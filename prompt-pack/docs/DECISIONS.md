# Decisions

## Decision 001: Product is Atlas

Atlas is the main product name. Clawd is the scout/companion inside Atlas.

## Decision 002: Free users still get Clawd

Free Clawd is a companion. Paid Clawd is a hosted daemon.

## Decision 003: $20/month is Hosted Clawd Daemon

The paid product is persistence, business memory, campaigns, quests, evidence, and progress.

## Decision 004: Alpha avoids full 3D

Alpha uses a fake-but-beautiful voxel map using React + SVG/Canvas.

## Decision 005: County data starts curated

Do not build live ingestion first. Use curated county packs for the killer demo.

## Decision 006: First wedge is Eastvale mobile detailing

The first demo prompt is: "Drop Clawd in Eastvale for a mobile detailing business."
