# Atlas Asset Pack Spec

## Purpose

Atlas needs an original icon/asset system before UI code gets too far.

## Asset lanes

### Reference
Mood boards and concept images. These are for inspiration only.

### Original production assets
Assets that Atlas can ship.

## Required Alpha assets

### App identity
- Atlas app icon
- Atlas wordmark placeholder
- Clawd paw/compass mark
- Hosted Clawd badge
- Scout Drop pin
- Campaign clipboard icon

### Clawd states
- idle
- scouting
- excited
- blocked
- daemon mode
- level up

### Voxel tiles
- residential tile
- commercial/plaza tile
- warehouse tile
- road/freeway tile
- opportunity marker
- scouted marker
- campaign quest marker

## Style

High-quality voxel/pixel hybrid.  
Dark interface.  
Emerald/blue/purple glow accents.  
Clawd should feel like a local scout, not a generic cute mascot.  
Avoid copying OpenAI/Codex/third-party pet assets.

## Output formats

For Codex placeholder stage:
- SVG icons
- simple PNG exports optional
- JSON manifest

For final art stage:
- PNG/WebP sprites
- SVG icons
- sprite sheet metadata
- favicon/app icon sizes
