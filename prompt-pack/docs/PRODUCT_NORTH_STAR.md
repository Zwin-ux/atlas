# Atlas Product North Star

## Product

**Atlas** is a ChatGPT app that turns counties into voxel worlds.

Users can explore counties with **Clawd Companion** for free. When they are ready to act, they can pay $20/month to host **Clawd Daemon**, which saves business memory, Scout Drops, campaigns, quests, evidence, and progress.

## Tagline

Drop Clawd anywhere. Turn the location into a campaign.

## Core loop

Explore county → Ask data → Drop Clawd → Scout location → Generate campaign → Create quests → Submit evidence → Level up Clawd.

## First killer demo

User says:

> Drop Clawd in Eastvale for a mobile detailing business.

Atlas should show:
- voxel Inland Empire / Riverside county-style map
- Clawd landing on Eastvale
- opportunity zones
- scout report
- local campaign plan
- quest preview
- Host Clawd upgrade moment

## What Atlas is not

- Not a generic chatbot
- Not a normal map clone
- Not a full 3D game in Alpha
- Not a spam automation tool
- Not a creepy people-targeting tool
- Not a SaaS dashboard with a mascot slapped on

## What Atlas is

- Voxel county intelligence
- Local business campaign planner
- AI scout companion
- Action quest system
- Hosted daemon upgrade
