# Atlas Codex Prompt Pack

This pack is a Codex-ready pre-production system for building **Atlas**.

**Atlas** is a ChatGPT app that turns counties into high-quality voxel worlds. Free users explore local data with **Clawd Companion**. Paid users can host **Clawd Daemon** for $20/month to save business memory, Scout Drops, local campaigns, quests, evidence, XP, and progress.

## First killer demo

> Drop Clawd in Eastvale for a mobile detailing business.

The Alpha should render a voxel county view, show Clawd landing in Eastvale, generate a scout report, preview a local campaign, show quest previews, and explain the Hosted Clawd upgrade.
