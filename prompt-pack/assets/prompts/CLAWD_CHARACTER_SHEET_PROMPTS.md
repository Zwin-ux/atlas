# Clawd Character Sheet Prompts

## Main character sheet
Design an original voxel/pixel companion named **Clawd**, a small local business scout daemon for Atlas. Clawd should feel like a friendly scout dog/fox/daemon hybrid with a small pack, compass tag, and expressive eyes. Show states: idle companion, scouting, excited, blocked, hosted daemon mode, level up. High-quality voxel/pixel hybrid, dark console UI presentation, original IP, no resemblance to OpenAI/Codex assets or existing game characters.

## Clawd daemon mode
Design Clawd in hosted daemon mode: slightly upgraded gear, glowing cloud/server backpack, confident scout pose, purple/emerald energy, still friendly and small, premium voxel sprite style, transparent background.
