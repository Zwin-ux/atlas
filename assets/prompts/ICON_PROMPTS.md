# Atlas Icon Prompts

## App icon prompt
Create an original app icon for **Atlas**, a voxel county intelligence app. The icon should show a stylized isometric county tile with a glowing compass/paw marker, dark navy background, emerald and electric blue highlights, premium app-store quality, readable at small sizes, no text, no OpenAI logo, no third-party mascot, no map pin cliché unless stylized.

## Hosted Clawd badge prompt
Create an original badge icon for **Hosted Clawd Daemon**. It should combine a small paw/daemon mark with a cloud/server shape, premium voxel/pixel hybrid, dark background, purple and emerald glow, readable at 64px, no copied characters.

## Scout Drop pin prompt
Create an original location marker for **Scout Drop**. It should look like a glowing drop beacon on an isometric voxel tile, with subtle paw/compass detail, orange/emerald accent, clean silhouette.
