## Honest baseline — what "archetype" means today

Read from source, 2026-07-07:

| Lever | File / symbol | Per-archetype identity today |
|---|---|---|
| Classifier | `cityWorldGeneratedDistrictArchetypes.ts` → `selectGeneratedDistrictArchetype` | ✅ county → one of 6 archetypes by state/lat-long. Coarse but fine. |
| Zone layout | same file → `generatedZones` | ❌ **identical** residential/civic/commercial rectangles for all six; only **one** bonus zone differs (water-edge / desert-plaza / ridge-commons / east-commons). ±1-cell seed jitter. |
| Road grid | same file → `generatedRoadSeeds` | ❌ **identical** grid for all six; **one** bonus road differs. |
| Terrain | same file → `generatedHeightGrid` + `BASE_HEIGHT_GRIDS` | ✅ **6 distinct** height profiles (the only real identity today) + ±0.08 jitter. |
| Palette / material | `cityWorldParametricGenerator.ts` → `RESIDENTIAL_TEMPLATE_POOL` etc., resolved by `withBuildingMetadata` | ❌ palettes keyed by **building kind**, global. A desert home and a coastal home draw the same beige set. **No regional identity.** |
| Landmark | `cityWorldParametricGenerator.ts` (~L229) | ❌ "one water tower on the highest non-water block corner" — **same landmark for every archetype**. |

**Verdict:** archetype identity ≈ terrain profile + one bonus zone. This is
exactly the "six templates × jitter" failure mode NS-6 names. A cold
screenshot of a desert county and a coastal county are near-indistinguishable
apart from ground slope. **Fails the "which one is curated?" crop test.**

Scale facts (measured 2026-07-07, unchanged): 3,222 counties indexed, 5.8ms
mean generation, ~780KB scene JSON, 0 window-budget failures across a
120-county probe. The infrastructure already scales; this program is quality,
not throughput.

## The four levers to region-true identity

Ordered by visual leverage per unit of risk.

### Lever 1 — Regional palettes (biggest lever, currently absent)
Give each archetype a body/roof/ground/terrain palette that reads as its
region. Thread the archetype (or a resolved `RegionalPalette`) into the
building-metadata resolver and terrain tone so it is authored by the
compiler, not sniffed at draw time (matches the 0.73F facade contract).

| Archetype | Read | Body | Roof | Terrain tone |
|---|---|---|---|---|
| `desert_basin` | adobe / terracotta | sand, adobe, pale ochre | terracotta, rust, clay | sun-bleached tan, dry sage |
| `coastal_grid` | whitewash / sea | whitewash, pale sand, foam | navy, weathered teal, slate | pale sand, shore green, water |
| `mountain_valley` | timber / stone | timber brown, stone grey, cedar | slate, dark green, iron | pine green, granite, snow cap |
| `prairie_town` | grain / barn | grain gold, cream, barn red | barn red, tin silver, green | prairie gold-green, tilled soil |
| `river_town` | brick / moss | brick red, ochre, moss stone | slate blue, moss green, tin | river green, mud bank, water |
| `metro_grid` | concrete / glass | concrete grey, warm tan, glass blue | grey, dark steel, copper | urban grey-green, paved |

Insertion point: add an optional `regionalPalette` to
`CityWorldParametricSpec` (or pass `archetype`) that `withBuildingMetadata`
and terrain tone consult; when absent, current behavior is byte-identical
(curated Riverside untouched).

### Lever 2 — Massing & zone-layout variants
Replace the shared `generatedZones`/`generatedRoadSeeds` layout with
per-archetype arrangements and building-template weighting:
- `metro_grid` — taller, denser core; tighter block grid; apartment weight up.
- `desert_basin` — low wide sprawl; large dry plaza; setback single-story.
- `coastal_grid` — waterfront commercial strip fronting the water edge; homes step back from shore.
- `mountain_valley` — elevation-terraced blocks; civic on the ridge; fewer, larger lots.
- `prairie_town` — wide low grid; a grain/agricultural district; long straight roads.
- `river_town` — linear town following the river; dock district; bridge crossing.

### Lever 3 — Region-true landmark
Replace the universal water tower with a per-archetype signature landmark on
the archetype-appropriate host cell:
- coastal → pier / small lighthouse on the water edge
- desert → water tower on the highest mesa block (keep)
- mountain → lodge / ridge marker on the highest block
- prairie → grain silo cluster in the ag district
- river → dock + bridge marker at the water edge
- metro → civic tower on the civic core

Stay inside the prop budget (`maxPropCommands` 90) and forbidden set
(`{parked_car, cloud}`) — landmarks are geometry/props, not new dependencies.

### Lever 4 — Terrain refinement
Terrain is already differentiated; add archetype terrain *features* the
renderer already supports (cliff courses, beach shore, stacked relief):
desert mesa rims, coastal beach basin (exists), mountain cliff courses,
river banks. Tune amplitude so overview reads region even before palette.

## Gate promotion — floors → curated-equivalence

Today's parity verifier is a *floor* (submittable). NS-6 asks it to certify
*curated-equivalence*. Promote `verify-generated-district-parity.mjs`:

1. **Palette distinctness (NEW):** assert any two archetypes render
   measurably different dominant body/roof/terrain palettes — two archetypes
   may never resolve the same palette. This is the structural guard that kills
   "six templates × jitter" permanently.
2. **Regional-landmark presence (NEW):** assert the resolved landmark kind
   matches the archetype's signature.
3. **Composition band → Eastvale-relative:** raise composition floor from
   ≥0.60 toward Eastvale's measured band (measure curated first, set the
   band, then require generated to sit inside it — not just above a low bar).
4. **Hold the won gates:** clone pressure ≤0.30, contact ≥0.95, roof safety,
   fabric floor, Graphics ≤1,600 worst-window (currently 844), rebuild ≤350ms
   (currently 10–25ms). These are NS-1/NS-2 greens — budget verification, not
   ambition.

## Batch verification — the full index
Extend the 120-county probe into a batch sweep asserting per-archetype

counties (Graphics ceiling holds at the *largest* county, not the average).

mitigate (packet compression / window-on-demand) only if it pinches.
