## 1. Chosen direction — Instrument

A crisp hairline **instrument layer** over a full-bleed map world. Two-layer grammar with a hard
boundary:

- **CHROME** (every overlay, panel, control, label) inherits ChatGPT — achromatic, system type,
  alpha hairlines, near-zero elevation. The widget reads as *a ChatGPT surface that happens to
  contain a map.*
- **WORLD** (the map canvas) is the **only** place Atlas's own color and charm live.

Hierarchy comes from **type + ink-steps + alignment + hairlines**, never from fills, color, or
shadow. Hover is a **tint, never a lift**. The honesty line is plain tertiary text, never a banner.
**One** design system in the file — the legacy voxel layer is excised/quarantined.

## 2. Token system (add to top of `web/src/styles.css`)

Three tiers. Every `rgba()/hex` literal in the `city-world-*` layer is find-replaced onto these.

**Tier 1 — primitives:** a `--gray-0..1000` scale that inverts for dark; black/white alpha steps
`--alpha-05 / -10 / -15`. No brand hue.

**Tier 2 — semantics:**
- `--surface: rgba(255,255,255,.92)` (light) / `rgba(33,33,33,.92)` (dark)
- `--ink: #0d0d0d` / near-white · `--ink-2` (~gray-500 secondary) · `--ink-3` (tertiary caption)
- `--border: rgba(0,0,0,.10)` · `--border-subtle: rgba(0,0,0,.05)`
- Remapped wholesale under `[data-theme='dark']`, with a `prefers-color-scheme` fallback.

**Tier 3 — aliases:** existing `--city-panel / --city-border / --atlas-*` names mapped onto the
semantics so every `city-world-*` selector keeps working unchanged.

**Status hue** exists ONLY on status dots/words (`tone-high/medium/watch`, `severity-low/medium/high`
from the existing `--atlas-*` tones) — never as fills or panel borders.

**Primary action = solid ink** (near-black light / near-white dark), exactly like ChatGPT's own
primary buttons. **The yellow accent is retired from chrome entirely** (owner-approved). It survives
only on tiny status dots. Map greens desaturate ~15% toward terrain calm; dark theme dims the canvas
with one `filter: brightness(.82) saturate(.9)` on `.city-world-renderer` (do NOT re-author art).

### Typography
System stack everywhere: `system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif`. **Drop Inter
from the front** (not guaranteed in the iframe; its 850/950 weights silently collapse). Four-step
integer scale: `11/1.35` tertiary caption · `12/1.4` secondary · `13/1.45` body · `14/1.3` semibold
heading (one optional `16px` focal number). Weights capped at **500/600/700**. Uppercase demoted to
**one** kicker level (`11px / 600 / 0.06em`). `font-feature-settings: 'tnum'` on every numeric
readout. Eliminate all fractional sizes (8.5/9.5/10.5/11.5) and 750–950 weights.

### Spacing
4px-base ladder only: `4/8/12/16/20` (24 for panel gutters). Symmetric paddings (kill the 1px-nudge
four-value paddings). Overlay inset: 12px ≤640px, 16px above, plus `env(safe-area-inset-*)` on
edge-pinned elements.

### Elevation
`--hairline: 1px` (0.5px at hidpi) in `--border-subtle` is the default edge for everything. **Exactly
two shadow tokens:** `--elev-1` reserved for the **open preview panel, the place tray, and the
location block** — everything else gets border + background only. One panel material:
`color-mix(in srgb, var(--surface) 90%, transparent)` + `backdrop-filter: blur(12px) saturate(1.1)`.
Radii: **8 controls / 12 panels / 16 outer widget clip**. Remove ALL `999px` pills except geometric
necessities (scrollbar thumb, tone dots). Delete all 3px/4px accent-edge borders and 6–36px blur
drop-shadows. Focus ring: `2px solid var(--ink)`, offset 2px (replaces the invisible pale-yellow glow).

### Motion
Three durations, one curve: `--dur-instant 90ms` (hover/active tint) · `--dur-quick 140ms`
(collapsible/fades) · `--dur-move 200ms` (sheet/panel in-out, county crossfade). `--ease-out:
cubic-bezier(.25,.46,.45,.94)`. Nothing >240ms. **Only `transform` + `opacity` animate.** Delete all
`translateY(-1px)` hover lifts → hover = `background var(--alpha-05)` tint; `is-active` = fill +
weight (so hover ≠ selected). One ambient motion: `.city-world-place-pulse` as a 2.4s opacity ring.
Global `@media (prefers-reduced-motion: reduce)` guard.

## 4. Dark theme + accessibility (design-review additions)

- **Theme plumbing:** read `window.openai.theme` at mount, listen for `globals-change`, stamp
  `data-theme` on the root, remap only Tier-2 tokens under `[data-theme='dark']` with a
  `prefers-color-scheme` fallback. Ensure the iframe root background matches the shell (no white flash).
- **Contrast:** verify body ≥ 4.5:1 and tertiary ≥ 4.5:1 as-composited over the *lightest* map green
  in BOTH themes. Honesty copy stays plain meta text, never a styled callout.
- **Focus:** `focus-visible` = 2px solid ink offset 2px on every interactive element.
- **Mobile coexistence:** while `data-qa-preview-kind` is set, collapse the left column to just the
  location line (CSS keyed off a shell state class or `:has()`), cap the mobile preview at ~52dvh, and
  surface the selected place as a one-line strip in the preview head so map taps still respond.
