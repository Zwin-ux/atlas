# Plan: 0.79 VISUAL GUARANTEE — provable map quality for all 3,222 counties

## Context

Owner question: "how can we guarantee proper effective map visuals for the
entirety of the US?" Answer is architectural — six layers, four already live
(full-index structural gates, quantified taste floors, real-host NS-0
acceptance, regression-memory gates) and two missing. This program builds
the missing two, formalizes the sampling layer, and wires everything into
the standing certification ladder so "the whole US looks right" becomes a
checkable claim on every commit. (0.78 Real Geography, already approved and
in flight, supplies layer 1 — correctness by construction; its geometry-
truth gates [silhouette IoU, water/road presence] stay in that program.)

## Packets (packet law from docs/PRODUCTION_ROADMAP.md applies)

### 0.79-1 — Per-county visual score + worst-tail report (codex; core+script)
- New `scripts/build-visual-score-report.mjs`: for ALL 3,222 counties,
  compile (reuse the sweep's compile path in
  `scripts/verify-archetype-identity-sweep.mjs` — same loaders, same spec
  pipeline) and score each county 0-100 from ALREADY-COMPUTED signals:
  composition occupancy (generatedOverviewFocus scorer), water visibility
  (0.77-2 floors), vegetation density vs band midpoint, palette distance to
  nearest archetype neighbor, massing signature distance, road-class mix
  sanity, label-grammar coverage. Weights in ONE exported table (tunable,
  diffable). Output: `artifacts/visual-score/report.json` + REPORT.md with
  national histogram + the WORST-50 list (slug, score, failing signals).
- New sweep gate (additive): national median >= floor (start 70), no county
  below hard floor (start 45) — floors chosen from the first real
  distribution, then ratcheted deliberately like every band.
- Human loop: worst-50 slugs feed the emulator screenshot flow
  (`verify-emulator-audit.mjs --county ...`) for owner review; every fix
  raises the floor. This is triage-by-math, eyes-where-it-matters.

### 0.79-2 — Challenge-set pixel-snapshot regression (codex; script only)
- New `scripts/verify-visual-snapshots.mjs`: renders the 16 challenge
  counties (list already in `scripts/build-county-geo-packs.mjs` CHALLENGE)
  through the EXISTING emulator capture path (reuse `scripts/lib/cdp.mjs`
  unclipped-screenshot recipe, desktop light only for determinism), then
  perceptual-hash compare (aHash/dHash implemented inline, no deps) against
  committed baselines in `artifacts/visual-baselines/`.
- Behavior: hash distance <= threshold -> pass; above -> FAIL listing the
  counties, with `--update-baselines` writing new ones (a DELIBERATE act,
  committed with justification — same discipline as band changes).
- Caveat handled: SwiftShader nondeterminism — hash tolerance calibrated by
  running the same build twice and setting threshold above self-noise,
  below real-change signal; report both numbers in the packet note.

### 0.79-3 — Stratified rotating sampler (codex; script only)
- New `scripts/pick-challenge-sample.mjs`: deterministic weekly sample
  (seed = ISO week) of 16 counties stratified by archetype x urbanization
  tier x water band x census division (all already on
  `CountyGenerationParameters` / `US_COUNTY_FACTS`), always including any
  stratum never-yet-sampled (coverage ledger in
  `artifacts/visual-score/sample-ledger.json`). Prints the
  `verify-emulator-audit.mjs --county ...` command ready to run.
- Roadmap P4.1 retargets to this (replaces hand-picked lists).

### 0.79-4 — Ladder wiring + doctrine (reviewer; docs + adapter)
- Certification ladder in `docs/PRODUCTION_ROADMAP.md` + codex adapter
  gains: visual-score gate (every core-visual packet) and snapshot gate
  (every renderer/compiler packet). NORTH_STARS Spend rules: worst-50
  review is a standing reviewer duty each visual cycle.
