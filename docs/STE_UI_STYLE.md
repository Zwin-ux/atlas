# Atlas UI language (STE-inspired)

Atlas UI microcopy follows **principles** from
[ASD-STE100 Simplified Technical English](https://www.asd-ste100.org/)
(Issue 9). We do **not** claim full STE certification or redistribute the
official dictionary (copyright ASD).

## Rules for Atlas UI

1. **One term, one meaning.** Use: map, place, pin, note, county, session.  
2. **Short.** Labels ≤ 6 words. Status lines = one short sentence.  
3. **Active voice / imperative** for actions: `Save note`, `Select a place.`  
4. **Simple present** for status: `Pins and notes stay in this chat only.`  
5. **No synonym noise.** Do not mix Save / Keep / Store / Commit.  
6. **No marketing filler.** Ban: seamless, leverage, empower, revolutionary, demo, alpha, coming soon.  
7. **One fact + one limit** for coverage:  
   `This map is generated. Town names are from the Census.`  
8. **Consistent project terms (technical nouns):**  
   county · place · pin · note · map · session · chat  

## Preferred strings

| Role | String |
|------|--------|
| Empty place | `Select a place.` |
| Note placeholder | `Write a note for {place}.` |
| Save action | `Save note` |
| Pin action | `Pin place` |
| Session limit | `Pins and notes stay in this chat only.` |
| First run | `Drag the map. Pinch to zoom. Tap a place.` |
| Generated map | `This map is generated. Town names are from the Census.` |
| Open proof map | `Open Riverside map` |
| Note saved (a11y) | `Note saved.` |

## Banned in map chrome

- Drop Clawd, Scout Drop, campaign, Hosted Clawd (unless user opens save flow later)  
- demo, alpha, trial, coming soon  
- Pick a place → use **Select a place.**  
- Save (alone) on note control → **Save note**
