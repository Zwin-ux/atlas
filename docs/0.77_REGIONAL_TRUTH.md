# 0.77 — Regional Truth program

Opened 2026-07-11 after a 16-county multi-region challenge sweep (all cells
158-gate green, but the CEO crop test failed on truth). Evidence:
`artifacts/emulator/audit/` screenshots for loving-tx, kalawao-hi,
summit-co, miami-dade-fl.

## Findings (eyes-on, production emulator path)

1. **Population-blind archetypes** — loving-tx (pop 64, emptiest county in
   America) renders a dense metro downtown with civic tower; miami-dade-fl
   (2.7M) renders a sleepy small town. Seed noise decides urbanity.
2. **Coastal first-frame sea** — coastal counties (miami-dade, kalawao,
   honolulu) open with no visible ocean. Known E10 carry-forward, now
   confirmed product-level across regions.
3. **Tropical reads arid** — Hawaii ground/vegetation reads sandy-dry;
   tropical humid latitudes need lush ground + palm-dominant grammar.
4. **Mountain relief invisible at overview** — summit-co (Rockies) opens
   flat; palette/lodge right, elevation drama absent from the frame.
