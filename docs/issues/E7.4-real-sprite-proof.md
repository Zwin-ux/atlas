# E7.4 Real Sprite Proof

## Summary

Add the first tiny real sprite proof to the city-world atlas lane while keeping
primitive fallback as the default safety net.

## Product Constraints

- The visible product remains the full-screen Eastvale city map.
- The first sprite proof should improve a small repeated detail, such as sticker
  pins or shop signs.
- Missing textures must never blank the map.

## Anti-Scope

- No full asset pipeline.
- No whole-map art replacement.
- No new dashboard or panel surface.
- No Three.js, auth, Stripe, persistence, live ingestion, or provider payloads.

## Acceptance

1. One real texture asset exists under `packages/assets/city-world/textures/`.
2. Manifest frame and anchor data point at the asset.
3. Resolver can return sprite mode for the asset when loaded.
4. Primitive fallback still works for every missing texture.
5. Preview remains map-first and nonblank.
6. Build verification passes for web and widget surfaces.
