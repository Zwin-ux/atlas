# E8.0 USA Engine API Foundation

## Summary

Make Atlas ready to become a USA-scale map engine without trying to render the whole country in one pass.

This is a backend/API architecture slice. The default UI remains the full-screen city map. The goal is to make future counties and districts plug into the same contracts that Eastvale uses today.

## Requirements

- Add normalized world identity contracts for:
  - country
  - state
  - county
  - district
  - place
- Define provider-independent API response contracts for county and district world data.
- Keep renderer output contract-driven through `VoxelScene` and `CityWorldScene`.
- Add cache key and TTL policy for provider-derived signals.
- Extend `GeoDataAdapter` planning around county/district/place lookup, without exposing raw provider payloads to the renderer.
- Keep Google Maps Platform as the first provider lane behind adapters.
- Keep Railway as the assumed live backend lane.

## Proposed API Shape

- `GET /api/world/us/states`
- `GET /api/world/us/states/:stateCode/counties`
- `GET /api/world/counties/:countySlug`
- `GET /api/world/counties/:countySlug/districts/:districtSlug`
- `POST /api/world/compile-city-scene`

## Acceptance

1. `docs/USA_ENGINE_ARCHITECTURE.md` is treated as the USA-scale engine brain. Done.
2. Core types can express normalized country/state/county/district/place identity without renderer coupling. Done.
3. API contracts are documented before implementation. Done.
4. Google/provider data remains behind adapters. Done.
5. No new dashboard UI, campaign surface, auth, Stripe, or persistence is added. Done.
6. Focused typecheck/test commands pass after the slice. Done.

## Implemented Foundation

- `packages/core/src/world/types.ts`
- `packages/core/src/world/NationalWorldService.ts`
- `packages/core/test/national-world-service.test.ts`
- `GET /api/world/us/states`
- `GET /api/world/us/states/:stateCode/counties`
- `GET /api/world/counties/:countySlug`
- `GET /api/world/counties/:countySlug/districts/:districtSlug`

The first implementation is curated-data backed and intentionally supports Riverside/Eastvale only. It proves the contract shape for future provider-backed counties without touching the renderer.

## Anti-Scope

- Do not render the whole USA.
- Do not add a giant national canvas.
- Do not persist user notes/stickers yet.
- Do not add a database until Hosted Clawd storage is the active quest.
- Do not use provider data directly inside Pixi or React.
