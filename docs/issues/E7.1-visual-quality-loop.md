# E7.1 Visual Quality Loop

## Summary

E7.0 is accepted as the first Alpha baseline. E7.1 improves the visual quality of the full-screen Pixi city map without changing the product shape.

The target remains a colorful Eastvale city map that opens directly in `/preview`, with React limited to small HUD overlays and Pixi owning the map, animation, hit testing, labels, pins, and ambient life.

## Scope

- Improve code-generated voxel art now.
- Add atlas-ready metadata so future real sprite and tile atlases can replace primitives cleanly.
- Keep all visible map data behind `CityWorldScene`.
- Keep stickers and notes session-only.
- Keep Apps SDK `structuredContent` concise and full scene data in `_meta`.

## Requirements

- Buildings render by category:
  - homes
  - shops
  - gym
  - apartments
  - civic
- Roads feel authored:
  - curbs
  - lane marks
  - crosswalks
  - driveway cuts
  - intersection treatment
- Terrain gains readable variation:
  - grass variants
  - park paths
  - plaza paving
  - water edge accents
  - grounded shadows
- Props become denser:
  - tree clusters
  - benches
  - parked cars
  - shop signs
  - streetlights
  - shrubs
  - water details
- Ambient actors read clearly:
  - cars have bodies, windows, lights, and road alignment
  - walkers have head/body shapes and a subtle step motion
  - Clawd remains a Pixi placeholder until a later Rive pass

## Required Non-Goals

- No new dashboard shell.
- No card page.
- No report panel.
- No side panel.
- No campaign flow.
- No persistence.
- No backend expansion.
- No Three.js.
- No Lottie for map objects.
- No new dependency.

## Acceptance

1. `/preview` still opens to a single full-screen city map.
2. The first frame reads as a dense, colorful city, not placeholder slabs.
3. Drag, wheel zoom, pinch zoom, hover, place click, sticker drop, and note save work.
4. Desktop and mobile viewports have no horizontal overflow.
5. No visible campaign/report/signal/risk/tactical/board language appears in the default map UI.
6. `pnpm test:core`, `pnpm typecheck:starter`, `pnpm --dir apps/widget typecheck`, `pnpm build:web`, `pnpm --dir apps/widget build`, and `pnpm build:server` pass.
