# E8.6 County Question Slice

## Summary

Add the smallest read-only county-question capability for the Riverside/Eastvale
demo. The tool should answer from curated Atlas data and normalized world
contracts only.

## Anti-Scope

- No live ingestion.
- No saved memory.
- No RAG stack.
- No database.
- No broad Q&A engine.
- No raw Google payloads.
- No campaign execution.
- No new dashboard UI.

## Acceptance

1. Tool is read-only, non-destructive, and closed-world.
2. Answers use curated Riverside pack facts and source notes only.
3. It can explain why Eastvale is the first slice.
4. It can explain which curated signals support mobile detailing.
5. It narrows or refuses unsupported county/business claims.
6. It does not save state or claim live market truth.
7. Verification covers one supported and one unsupported question.
