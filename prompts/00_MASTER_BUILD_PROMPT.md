# Codex Prompt 00: Atlas Master Build Prompt

You are building Atlas.

Atlas is a ChatGPT app that turns counties into voxel worlds. Users explore local data with Clawd Companion for free, then can pay $20/month to host Clawd Daemon for persistent business memory, saved Scout Drops, campaigns, quests, evidence, XP, and progress.

## Product loop

Explore county → Ask data → Drop Clawd → Scout location → Generate campaign → Create quests → Submit evidence → Level up Clawd.

## First killer demo

"Drop Clawd in Eastvale for a mobile detailing business."

## Build philosophy

Make one excellent Alpha flow. Do not build the whole platform.

Do not:
- Add Stripe/Auth/GitHub/Claude until later phases.
- Build full 3D.
- Build spam automation.
- Over-test.
- Invent live data.
- Copy third-party pet assets.

Return after every patch:
1. Files changed
2. What works now
3. What was intentionally skipped
4. Verification command/result
5. Next quest
