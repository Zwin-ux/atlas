# Formative usability study / optional evidence lane

Recruit a small consenting group unfamiliar with Atlas. The initial plan is eight participants; this is a proposed formative sample, not proof of demand or statistically representative research. Do not create a tracking platform to run it.

## Tasks without coaching

1. Open a supported named place and explain what boundary/point the map represents.
2. Inspect another place and ask about it without retyping the full name.
3. Broaden to a parent geography, then return to the previous view.
4. Resolve an ambiguous name.
5. Recover from an intentionally induced map fetch failure.
6. Explain whether Atlas can provide driving directions and current weather.

Use a different supported fixture for each participant/order where practical. For suitable comprehension questions, compare against a text-only answer and counterbalance task order. Do not ask only whether the map is attractive.

## Record with consent

Anonymous participant code; task; outcome; help needed; wrong mental model; selected identity; scope misunderstanding; recovery; one qualitative quote if permission permits. Avoid collecting precise location, account credentials, conversation history, or unnecessary personal details. Store raw recordings privately and use only permissioned material in a public demo.

Proposed initial signal: at least six of eight complete the main journey without coaching. Treat every factual mismatch seriously regardless of aggregate completion. Missing participants remain “not run”; agents cannot roleplay eight humans and report a passed study.

Implementation and local release preparation can continue without recruited participants. Findings reopen the affected task/acceptance evidence, not the whole roadmap. A study report distinguishes observed behavior, interpretation, and next experiment.
